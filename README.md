# 海洋・港湾構造物維持管理士 学習サイト

択一式（過去問＋予想問題）と、記述式対策の穴埋め問題をブラウザで解くための静的サイトです。
サーバー不要・すべてブラウザ内で動作し、**GitHub Pages にそのまま公開**できます。

## 収録内容
- **択一演習**：全272問
  - 平成27〜30年度・2019〜2025年度の過去問（各年度20問）＋予想問題32問（うち令和8年改定ガイドライン関連を多数収録）
  - 選択肢ごとの解説つき。図（電位分布・塩化物イオン濃度分布など）も収録
  - 年度／出題範囲（過去問・予想）／問題数を選んで出題。1問ずつ即時採点、最後に正答率と振り返り
- **穴埋め演習**：全41テーマ
  - 記述式解答例（令和8予想問題集・過去問解説集）の重要語句・数値を、空欄をタップして答えを表示する暗記カード方式で確認。解説つき
  - 令和8改訂GL／論述テーマ（気候変動・供用期間延長・DX・大規模地震）／実務4段（桟橋・鋼矢板・消波）／重要数値／答案術まで収録

> ⚠️ 過去問の正答・解説は公式発表ではなく、基準書に基づく**参考**です。必ず原典でご確認ください。

## GitHub で公開する手順（GitHub Pages）

### 方法A：ブラウザだけで公開（かんたん）
1. GitHub にログイン →「New repository」で新規リポジトリを作成（例：`iji-quiz`）。Public を選択。
2. リポジトリ画面の「Add file ▸ Upload files」で、このフォルダ内の
   `index.html` と `css` `js` `data` フォルダを**まるごとドラッグ＆ドロップ**してコミット。
3. リポジトリの **Settings ▸ Pages** を開く。
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** に設定して Save。
5. 1〜2分後、`https://<ユーザー名>.github.io/iji-quiz/` で公開されます。

### 方法B：git コマンドで公開
```bash
cd 維持管理士学習サイト          # このフォルダへ移動
git init
git add .
git commit -m "維持管理士 学習サイト 初版"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/iji-quiz.git
git push -u origin main
```
その後、方法Aの手順3〜5で Pages を有効化してください。

## 問題の追加・修正のしかた
`data/takuitsu.js` / `data/anaume.js` をテキストエディタで開いて追記するだけです。

**択一を追加する例**（`window.TAKUITSU = [ ... ]` の中に追記）：
```js
{
  id: "2025-21", year: "2025", src: "past", kind: "点検診断",
  q: "問題文……最も適当なものはどれか。",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  ans: 2,                       // 正答の番号（0始まり＝選択肢3が正答）
  exp: "全体のポイント解説……",
  cexp: ["①の解説", "②の解説", "③の解説（これが答え）", "④の解説"], // 任意
  img: "data:image/png;base64,..."   // 図がある場合のみ（任意）
}
```
- `year` は年度（`"2025"` `"H30"` など、`"予想"` は予想問題）、`src` は `"past"`（過去問）か `"pred"`（予想）。
- `kind` はバッジに表示される分類名、`cexp` は選択肢ごとの解説（省略可）、`img` は図（base64、省略可）。

**穴埋めを追加する例**（`window.ANAUME = [ ... ]` の中に追記）：
```js
{
  id: "an-17", theme: "点検診断", src: "pred",
  text: "……通常は概ね【1】年ごとに点検を行う。",   // 【1】【2】が空欄
  blanks: [ { ans: ["5", "五"], hint: "数値" } ],   // ans は許容解答の配列
  exp: "解説……"
}
```
